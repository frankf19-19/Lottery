帳號登入 檢查中…

單一帳號:在任何裝置輸入同一組密碼登入,預測紀錄自動同步(儲存/刪除自動上傳、開網頁自動合併)。登入狀態會保留在此裝置,登出即清除。
初次設定(整個帳號只需做這一次,之後所有裝置都用密碼登入):
1. 到 GitHub → Settings → Developer settings → Fine-grained personal access tokens → Generate new token(免費)
2. Repository access 只勾選這個儲存庫;Permissions → Contents: Read and write → Generate
3. 把 github_pat_ 開頭的金鑰貼到下面,設定一組登入密碼(至少 8 碼,建議混合英數)
運作方式:金鑰會用你的密碼以 AES-256-GCM 加密後存到儲存庫(data/auth.enc),之後任何裝置輸入密碼即可解鎖並自動同步。密碼不會被上傳、也無法找回——忘記密碼時重新做一次初次設定即可。加密檔在公開儲存庫中,請務必使用有強度的密碼。
免責聲明:本站所有統計皆為歷史資料的描述性分析;彩券每期開獎為獨立隨機事件, 任何號碼組合的中獎機率完全相同,「熱號」「冷號」「遺漏」對未來開獎不具預測力。 策略選號器與預測核對僅供娛樂與選號輔助參考,請理性投注、量力而為。開獎結果與獎金以台灣彩券官方公告為準。
